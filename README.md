Maapstricht
Allows to calculate distance between two postal codes and gives an estimation of travel time by bike and foot

Description:
The program shows an interactive map of Maastricht that allows the user to enter a starting and an ending postal code, calculates and displays the shortest path to between those two, and gives an estimation of travel time by bike and foot.

Dependencies:
Jxmapviewer (version 2.5) library (included in folder) should be added in the "References Libraries"

How to run the program:
Run Main.java
